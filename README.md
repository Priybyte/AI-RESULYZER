# 🚀 AI Resume & Interview Analyzer (MERN Stack)

A full-stack web application designed to help job seekers optimize their resumes using AI and prepare for interviews through automated, context-aware analysis.

## ✨ Features

* **AI Resume Analysis:** Automatically scans and evaluates resumes against job descriptions, highlighting strengths, missing keywords, and actionable improvements.
* **Smart Interview Preparation:** Generates role-specific technical and behavioral interview questions based on uploaded resume data.
* **Google OAuth Authentication:** Secure and seamless user sign-in using Google Accounts.
* **Secure Backend API:** Built with Node.js and Express, implementing robust error handling, environment security, and MongoDB data persistence.
* **Modern Responsive Frontend:** Clean, fast user interface built with React and Vite.

---

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Tailwind CSS / Modern CSS, JavaScript (ES6+)
* **Backend:** Node.js, Express.js, RESTful APIs
* **Database:** MongoDB, Mongoose (Cloud-hosted via MongoDB Atlas)
* **Authentication:** Google OAuth 2.0 / JWT
* **Deployment:** Vercel (Frontend) & Render (Backend)
